# Business Analytics: Codespaces Environment

Welcome. This Codespace has everything you need for this module's Python
notebooks already installed: no setup required on your end.

## Getting started

1. Wait for the Codespace to finish setting up. The first time takes
   about 5 minutes.
2. Drag and drop the **contents** of the class folder you were given
   into this workspace, not the folder itself. If you see a subfolder
   appear here (e.g. `class-6-7/`) instead of files like `CLAUDE.md`
   directly, undo it and try again, dragging what's *inside* that folder.
3. Open a notebook. When asked to choose a kernel, pick the one called
   **Python (decision-suite)**.
4. You're ready to go.

If anything looks broken or missing, ask your instructor.
